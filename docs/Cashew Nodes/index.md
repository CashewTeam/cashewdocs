# Cashew Nodes 腰果节点组
Cashew Nodes（原B4D）是由我制作的一个 Blender 节点组资产库，旨在补充和拓展 Blender 的功能，简化几何节点的操作，提高用户使用 Blender 制作动态图形和卡通渲染的效率。<br />
