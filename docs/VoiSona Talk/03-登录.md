# 登录

Source: https://manual.voisona.com/en/talk/pc/2b6e9bc7efb18023b053f00f0cb54086

使用 VoiSona Talk 需要登录。登录后即可访问已订阅的语音库。

> ℹ️首次启动应用时，登录界面会自动显示。

1. 点击“Menu”按钮，然后选择“Help”>“Sign In”。

![](/assets/image/posts/voisona-talk/03-Signing-In/01.png)

1. 输入注册邮箱和密码，然后点击“Sign In”。登录成功后，登录界面会关闭。

![](/assets/image/posts/voisona-talk/03-Signing-In/02.png)
