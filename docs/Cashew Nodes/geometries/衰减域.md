# 衰减域
浮点缓动工具和各种衰减域

## 缓动

多种缓动函数，支持 In/Out/InOut 模式和镜像。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Type** | Menu | Sinusoidal | 缓动类型 |
| **InOut** | Menu | In | 缓动方向 |
| **Value** | Float | 0 | 输入值 |
| **From Min** | Float | 0 | 输入范围下限 |
| **From Max** | Float | 1 | 输入范围上限 |
| **To Min** | Float | 0 | 输出范围下限 |
| **To Max** | Float | 1 | 输出范围上限 |
| **Exponent** | Float | 2 | 指数（Pow 类型用） |
| **Base** | Float | 10 | 底数（Expo 类型用） |
| **Size** | Float | 1.70 | 弹性幅度（Back 类型用） |
| **Bounces** | Int | 4 | 弹跳次数（Bounce 类型用） |
| **Mirror** | Bool | false | 镜像缓动 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Value** | Float | 缓动后的值 |

## 圆柱域

圆柱形状的衰减域。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **钳制** | Bool | true | 钳制值在 0-1 |
| **位置** | Vector | (0,0,0) | 圆柱中心位置 |
| **旋转** | Rotation | (0,0,0) | 圆柱旋转 |
| **缩放** | Vector | (1,1,1) | 圆柱缩放 |
| **smooth** | Bool | false | 平滑衰减 |
| **From Max** | Float (0-1) | 0.25 | 开始衰减位置 |
| **To Min** | Float | 0 | 输出最小值 |
| **To Max** | Float | 1 | 输出最大值 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **系数** | Float | 衰减系数 |

## 波浪域

波浪形状的衰减域，支持球面和方向两种模式。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **球体/方向** | Bool | false | false=方向模式，true=球体模式 |
| **时间** | Float | 0 | 波浪动画时间 |
| **宽度** | Float | 0.5 | 波浪宽度 |
| **狭窄度** | Float | 1 | 波浪聚焦度 |
| **位置** | Vector | (0,0,0) | 波浪中心位置 |
| **方向** | Vector | (1,0,0) | 波浪方向（方向模式） |
| **衰减** | Float | 0 | 波浪衰减速率 |
| **最小** | Float | -0.1 | 输出最小值 |
| **最大值** | Float | 0.1 | 输出最大值 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **值** | Float | 波浪衰减值 |
