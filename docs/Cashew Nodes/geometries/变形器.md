# 变形器
模仿部分C4D功能制作的变形器节点。

## 弯曲

沿轴向弯曲几何体，支持角度和极限范围控制。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Geometry** | Geometry | — | 输入几何体 |
| **Angle** | Float | 0 | 弯曲角度 |
| **弯曲轴** | Vector | (0,0,1) | 弯曲方向轴 |
| **极限最小值** | Float (0-1) | 0 | 弯曲起始位置 |
| **极限最大值** | Float (0-1) | 1 | 弯曲结束位置 |
| **自定义中心** | Bool | false | 使用自定义中心点 |
| **Centre** | Vector | (0,0,0) | 自定义中心点 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 弯曲后的几何体 |

## 扭曲

沿轴向扭转几何体，支持角度范围和线性/平滑步进切换。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Geometry** | Geometry | — | 输入几何体 |
| **预览框** | Bool | false | 显示预览框 |
| **Centre** | Vector | (0,0,0) | 扭曲中心 |
| **扭曲轴** | Vector | (0,0,1) | 扭曲方向轴 |
| **Size** | Vector | (2.5,2.5,2.5) | 影响范围大小 |
| **Angle Min** | Float | 0 | 最小扭转角度 |
| **最大角度** | Float | 3.14 | 最大扭转角度 |
| **极限最小值** | Float (0-1) | 0 | 扭曲起始位置 |
| **极限最大值** | Float (0-1) | 1 | 扭曲结束位置 |
| **线性/平滑步长** | Bool | false | false=线性，true=平滑步进 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 扭曲后的几何体 |

## 斜切

沿轴向斜切几何体，支持底部/顶部偏移和弯曲效果。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Geometry** | Geometry | — | 输入几何体 |
| **预览框** | Bool | false | 显示预览框 |
| **Position** | Vector | (0,0,0) | 斜切位置 |
| **Size** | Vector | (1.5,1.5,1.5) | 影响范围大小 |
| **轴向** | Vector | (0,0,1) | 斜切方向轴 |
| **底部偏移** | Float | 0 | 底部偏移量 |
| **顶部偏移** | Float | 1 | 顶部偏移量 |
| **Angle** | Float | 0 | 斜切角度 |
| **弯曲** | Float | 0.5 | 弯曲程度 |
| **Smooth Step** | Bool | false | 平滑步进 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 斜切后的几何体 |

## 爆炸

将几何体按孤岛分解，产生爆炸飞散效果，支持旋转和缩放终点。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Mesh** | Geometry | — | 输入网格 |
| **实例模式** | Bool | false | 实例化模式 |
| **Split Edges** | Bool | true | 分离边缘 |
| **位置** | Vector | (0,0,0) | 爆炸中心 |
| **强度** | Float | 0 | 爆炸强度 |
| **速度** | Float | 10 | 飞散速度 |
| **终点尺寸** | Float | 0 | 终点缩放 |
| **随机特性** | Float | 0 | 随机性 |
| **角速度** | Float | 90 | 旋转速度 |
| **Seed** | Int | 0 | 随机种子 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 爆炸后的几何体 |

## 碎片

将几何体按孤岛从法线方向粉碎，产生碎裂效果。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Mesh** | Geometry | — | 输入网格 |
| **实例模式** | Bool | false | 实例化模式 |
| **Split Edges** | Bool | true | 分离边缘 |
| **Z** | Float | -1 | 碎裂偏移方向 |
| **轴向** | Vector | (0,0,1) | 碎裂方向轴 |
| **强度** | Float | 0 | 碎裂强度 |
| **终点尺寸** | Float | 0 | 终点缩放 |
| **随机特性** | Float | 0 | 随机性 |
| **角速度** | Float | 90 | 旋转速度 |
| **Seed** | Int | 0 | 随机种子 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 碎裂后的几何体 |

## 融化

模拟几何体融化效果，基于位置控制融化范围和强度。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Geometry** | Geometry | — | 输入几何体 |
| **位置** | Vector | (0,0,0) | 融化中心 |
| **轴向** | Vector | (0,0,1) | 融化方向 |
| **强度** | Float | 0 | 融化强度 |
| **半径** | Float | 0.5 | 融化影响半径 |
| **垂直随机** | Float | 1 | 垂直方向随机性 |
| **半径随机** | Float | 100 | 半径随机百分比 |
| **融解尺寸** | Float | 4 | 融解收缩尺寸 |
| **噪波缩放** | Float | 0 | 噪波扰动缩放 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 融化后的几何体 |

## 锥化膨胀

缩放几何体一端实现锥化或膨胀变形。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Geometry** | Geometry | — | 输入几何体 |
| **上限因数** | Float | 0 | 上方缩放因子 |
| **下限因数** | Float | 0 | 下方缩放因子 |
| **Axis** | Vector | (0,0,1) | 变形轴向 |
| **Squish** | Float | 0 | 挤压/拉伸 |
| **Center** | Vector | (0,0,0) | 变形中心 |
| **下限** | Float (0-1) | 0 | 变形起始位置 |
| **上限** | Float (0-1) | 1 | 变形结束位置 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 变形后的几何体 |
