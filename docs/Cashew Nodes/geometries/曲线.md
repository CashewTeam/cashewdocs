# 曲线

曲线相关节点

## 扫描

基于曲线生成网格，支持环状、偏移、宽度控制等。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Curve** | Geometry | — | 主曲线 |
| **Profile Curve** | Geometry | — | 轮廓曲线 |
| **曲线** | Object | — | 曲线对象 |
| **环状** | Bool | false | 曲线是否闭合 |
| **外偏移** | Float | 0.1 | 轮廓向外偏移 |
| **内偏移** | Float | 0.1 | 轮廓向内偏移 |
| **Set Spline Cyclic** | Bool | false | 强制样条循环 |
| **Fill Caps** | Bool | true | 填充端盖 |
| **Material** | Material | — | 材质 |
| **Start** | Float (0-1) | 0 | 扫描起点位置 |
| **End** | Float (0-1) | 1 | 扫描终点位置 |
| **起始宽度** | Float | 1 | 起点宽度倍率 |
| **终点宽度** | Float | 1 | 终点宽度倍率 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Mesh** | Geometry | 生成的网格 |

已知问题：扫描出来的形状宽度会不均匀

## 放样曲线_ETK

多条曲线放样生成网格，支持 U/V 方向分辨率控制。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Curves** | Geometry | — | 输入曲线组 |
| **U 分辨率** | Int | 32 | U 方向分段数 |
| **V 分辨率** | Int | 32 | V 方向分段数 |
| **U Min** | Float (0-1) | 0 | U 方向起点 |
| **U Max** | Float (0-1) | 1 | U 方向终点 |
| **V Min** | Float (0-1) | 0 | V 方向起点 |
| **V Max** | Float (0-1) | 1 | V 方向终点 |
| **周期：无\|U\|V** | Int | 0 | 周期性（0=无，1=U，2=V） |
| **Cap** | Bool | false | 填充端盖 |
| **使用间距** | Bool | false | 使用最小间距 |
| **Minimum Distance** | Float | 1 | 最小间距值 |
| **线性/立方** | Bool | true | true=线性，false=立方 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Mesh** | Geometry | 放样生成的网格 |
| **U 曲线** | Geometry | U 方向曲线 |
| **V 曲线** | Geometry | V 方向曲线 |
| **Size** | Int | 曲线数量 |
| **U 因素** | Float | U 方向因子 |
| **V 因素** | Float | V 方向因子 |
| **Rotation** | Vector | 旋转 |

## 曲线工具

修剪曲线和追踪曲线上的点。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Curve** | Geometry | — | 输入曲线 |
| **Start** | Float (0-1) | 0 | 修剪起点 |
| **End** | Float (0-1) | 1 | 修剪终点 |
| **Offset** | Float | 0 | 曲线偏移值 |
| **Value** | Float | 1 | 采样位置值 |
| **Set Spline Cyclic** | Bool | false | 强制样条循环 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Curve** | Geometry | 修剪后的曲线 |
| **Position** | Vector | 采样点位置 |
| **Tangent** | Vector | 采样点切向 |
| **Normal** | Vector | 采样点法向 |

## 曲线挤出

将轮廓曲线沿方向挤出为网格，支持切割分段。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Profile Curve** | Geometry | — | 轮廓曲线 |
| **起点封盖** | Bool | true | 起点端盖 |
| **终点封盖** | Bool | true | 终点端盖 |
| **三角填充** | Bool | false | 三角面填充 |
| **挤出距离** | Float | 0 | 挤出长度 |
| **挤出方向** | Int (1-3) | 1 | 1=X, 2=Y, 3=Z |
| **Cuts** | Int | 0 | 挤出方向分段数 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Mesh** | Geometry | 挤出网格 |

## 曲线旋转

将轮廓曲线绕轴旋转生成网格（类似车削/ lathe）。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Profile Curve** | Geometry | — | 轮廓曲线 |
| **起点封盖** | Bool | true | 起点端盖 |
| **终点封盖** | Bool | true | 终点端盖 |
| **三角填充** | Bool | false | 三角面填充 |
| **曲线方向** | Int (1-3) | 1 | 旋转轴方向 |
| **分辨率** | Int | 32 | 圆周分段 |
| **角度** | Float | 360 | 旋转总角度 |
| **半径** | Float | 0 | 旋转半径偏移 |
| **高度** | Float | 0 | 垂直偏移 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Mesh** | Geometry | 旋转生成的网格 |

## 曲线网格布尔

曲线与网格之间的布尔运算。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **差异/间/切片** | Int (0-2) | 0 | 0=差异，1=交集，2=切片 |
| **曲线** | Geometry | — | 曲线输入 |
| **网格** | Geometry | — | 网格输入 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **曲线** | Geometry | 布尔后的曲线 |
| **相交点** | Bool | 相交点选择 |

## 样条布尔

两条样条之间的布尔运算（并集/交集/差集）。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Curve** | Geometry | — | 第一条曲线 |
| **曲线** | Object | — | 第一条曲线对象 |
| **Curve** | Geometry | — | 第二条曲线 |
| **曲线** | Object | — | 第二条曲线对象 |
| **模式** | Int (1-3) | 1 | 1=并集，2=交集，3=差集 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Mesh** | Geometry | 布尔后的网格 |

## 追踪对象

根据物体运动轨迹生成样条曲线。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Input** | Geometry | — | 输入几何体 |
| **连接模式** | Bool | false | 连接各帧轨迹 |
| **实例模式** | Bool | false | 实例化模式 |
| **Step** | Int | 2 | 采样步长 |
| **Set Spline Cyclic** | Bool | false | 循环样条 |
| **随机编号** | Bool | false | 随机编号 |
| **Seed** | Int | 0 | 随机种子 |
| **Start Frame** | Int | 1 | 起始帧 |
| **End Frame** | Int | 60 | 结束帧 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 生成的轨迹曲线 |
