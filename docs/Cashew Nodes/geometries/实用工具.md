# 实用工具

## 模拟类

### 帧偏移

将几何体偏移指定帧数，用于创建延迟效果。

#### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Geometry** | Geometry | — | 输入几何体 |
| **延迟** | Int | 1 | 延迟帧数 |

#### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 延迟后的几何体 |

## 运算

### 加速度

计算物体在加速度下的位移。

#### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **初速度** | Vector | (0,0,0) | 初始速度 |
| **加速度** | Vector | (0,0,9.8) | 加速度 |
| **开始帧** | Int | 0 | 起始帧 |
| **结束帧** | Int | 0 | 结束帧 |
| **限制时间范围** | Bool | false | 限制时间范围 |
| **使用场景时间** | Bool | false | 使用场景实际帧 |
| **t** | Float | 0 | 手动时间输入 |

#### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **距离** | Vector | 位移量 |

### 矢量角度转弧度

将矢量角度转换为弧度。

#### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Vector** | Vector | (0,0,0) | 输入矢量角度 |

#### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Vector** | Vector | 弧度值 |

## 输入类

用于在修改器内输入物体和集合。

### 物体输入

在修改器内选择物体。

#### 输入

| 名称 | 类型 | 说明 |
|---|---|---|
| **网格** | Geometry | 网格几何体输入 |
| **Object** | Object | 物体选择 |

#### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Output** | Geometry | 物体几何体输出 |

### 集合输入

在修改器内选择集合。

#### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **开关集合输入** | Bool | false | 启用集合输入 |
| **Collection** | Collection | — | 集合选择 |
| **Separate Children** | Bool | true | 分离子物体 |
| **Reset Children** | Bool | true | 重置子物体变换 |
| **原始/相对** | Bool | false | 保持原始/相对变换 |

#### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Output** | Geometry | 集合几何体输出 |

## 选择类

### 摄像机剔除_ETK

判断实例是否在摄像机视野范围内。

#### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Camera** | Object | — | 参考相机 |
| **Camera FOV** | Float | 0.69 | 相机视场角（弧度） |
| **Resolution X** | Int | 1920 | 水平分辨率 |
| **Resolution Y** | Int | 1080 | 垂直分辨率 |
| **Padding** | Float | 0 | 边缘留白 |
| **扩展到摄像机** | Bool | false | 扩展到相机边界 |

#### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Mask** | Bool | 在视野内为 true |
| **Inverted** | Bool | 在视野外为 true |

### 在体积内

判断目标点是否在体积内部。

#### 输入

| 名称 | 类型 | 说明 |
|---|---|---|
| **目标** | Geometry | 目标网格（需为封闭体积） |

#### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **在内部** | Bool | 在体积内为 true |

### 扩展/收缩选择

通过迭代扩展或收缩选择区域。

#### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Geometry** | Geometry | — | 输入几何体 |
| **选择** | Bool | false | 初始选择 |
| **步骤** | Int | 1 | 扩展/收缩步数，正数扩展负数收缩 |
| **到面/到边** | Bool | false | false=到边，true=到面 |

#### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 处理后的几何体 |
| **选择** | Bool | 处理后的选择 |

### 按法线选择

根据面法线与方向向量的夹角选择面。

#### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **因子** | Float | 0 | 角度阈值 |
| **方向** | Vector | (0,0,1) | 参考方向 |
| **正/负** | Bool | false | false=正向，true=负向 |

#### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **选择** | Bool | 符合条件的面 |

### 获取面切向

获取面的切向和副切向信息。

#### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Geometry** | Geometry | — | 输入网格 |
| **Order** | Int (0-3) | 0 | 切向排序方式 |
| **对齐到方向** | Bool | false | 对齐到指定方向 |
| **Direction** | Vector | (1,0,0) | 参考方向 |
| **边角切向** | Bool | false | 使用边角切向 |

#### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 处理后的网格 |
| **面位置** | Vector | 面中心位置 |
| **切向** | Vector | 面切向 |
| **副切向** | Vector | 面副切向 |

### 边界区域选择

按轴向边界范围选择顶点/边/面。

#### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Geometry** | Geometry | — | 输入几何体 |
| **X** | Float (0-1) | 0 | +X 方向选择范围 |
| **Y** | Float (0-1) | 0 | +Y 方向选择范围 |
| **Z** | Float (0-1) | 0 | +Z 方向选择范围 |
| **-X** | Float (0-1) | 0 | -X 方向选择范围 |
| **-Y** | Float (0-1) | 0 | -Y 方向选择范围 |
| **-Z** | Float (0-1) | 0 | -Z 方向选择范围 |
| **反转** | Bool | false | 反转选择 |

#### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **选择** | Bool | 选择结果 |
