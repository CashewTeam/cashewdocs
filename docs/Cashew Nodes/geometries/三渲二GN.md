# 三渲二(几何节点组)

## 实体化描边_C

基于实体化修改器的动态宽度卡通描边节点组，支持通过相机距离控制描边宽度、噪声扰动和自定义材质。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Geometry** | Geometry | — | 输入几何体 |
| **描边宽度** | Float | 0.02 | 实体化偏移宽度 |
| **描边权重** | Float (0-1) | 1.0 | 描边权重控制（配合顶点权重） |
| **动态宽度** | Bool | false | 启用基于相机距离的动态宽度 |
| **相机** | Object | — | 相机对象（动态宽度需要） |
| **Material** | Material | OH_Outline_Material | 描边材质 |
| **噪波** | Bool | false | 启用噪波扰动 |
| **Scale** | Float | 0.05 | 噪波缩放 |
| **Scale** | Float | 5.0 | 噪波细节缩放 |
| **Detail** | Float (0-15) | 2.0 | 噪波细节层次 |
| **Roughness** | Float (0-1) | 0.5 | 噪波粗糙度 |
| **Lacunarity** | Float | 2.0 | 噪波间隙度 |
| **Distortion** | Float | 0.0 | 噪波畸变 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 带描边的几何体 |

### 使用说明

1. 连接输入网格到 **Geometry** 输入
2. 准备一个描边材质（纯黑色或自定义颜色）指定给 **Material**
3. 启用 **动态宽度** 并连接相机，可让描边在近处变细、远处变粗
4. 启用 **噪波** 使描边产生手绘般的抖动效果

## 平滑法向_C

Blender 自带平滑法线的增强版，支持通过属性命名自定义平滑法线，并提供法线向量输出。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Geometry** | Geometry | — | 输入几何体 |
| **Name** | String | NormalSmooth | 平滑法线属性名称 |
| **Iterations** | Int (0-2048) | 128 | 平滑迭代次数，越高越平滑 |
| **Weight** | Float (0-1) | 1.0 | 平滑权重 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 处理后的几何体 |
| **Normal** | Vector | 平滑法线向量 |

## 旋转属性传递_C

配合兰伯特、布林冯及面部SDF使用的辅助节点组，将灯光对象和面部对象的旋转信息传递到几何体属性中。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Geometry** | Geometry | — | 输入几何体 |
| **Sun** | Object | — | 灯光对象（传递其旋转到属性） |
| **Name** | String | SunRotation | 灯光旋转属性名称 |
| **脸部** | Object | — | 面部骨骼/空对象 |
| **Name** | String | FaceRotation | 面部旋转属性名称 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 添加旋转属性后的几何体 |

### 使用说明

连接灯光对象到 **Sun**、面部控制器到 **脸部**，节点组会将两者的旋转写入几何体属性，供着色器中的 SDF 面部阴影和光照计算使用。
