# 网格修改器

一些用于网格编辑的修改器。

## 内插面

在面中心生成内插面，支持偏移和深度。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Mesh** | Geometry | — | 输入网格 |
| **Selection** | Bool | true | 面选择 |
| **Offset Scale** | Float | 0.2 | 内插偏移 |
| **Depth** | Float | 0 | 内插深度 |
| **Even Offset** | Bool | true | 均匀偏移 |
| **相对偏移** | Bool | false | 相对偏移模式 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Mesh** | Geometry | 内插后的网格 |
| **Inner** | Bool | 内插面选择 |
| **Outer** | Bool | 外圈面选择 |

## 减面

通过角度、面积或距离等方式减少多边形数量。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Geometry** | Geometry | — | 输入几何体 |
| **Method** | Menu | 角度 | 减面方法 |
| **最大角度** | Float | 0 | 角度阈值 |
| **最小面积** | Float | 0 | 面积阈值 |
| **最小距离** | Float | 0 | 距离阈值 |
| **Strength** | Float | 0 | 强度 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 减面后的几何体 |

## 多边形FX

对每个多边形进行独立变换（位置/旋转/缩放）。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Mesh** | Geometry | — | 输入网格 |
| **样条模式** | Bool | false | 样条模式 |
| **Position** | Vector | (0,0,0) | 位置偏移 |
| **Rotation** | Vector | (0,0,0) | 旋转 |
| **Scale** | Vector | (1,1,1) | 缩放 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 变换后的几何体 |

## 实体化_C

为网格添加厚度，支持自定义偏移权重和材质。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Mesh** | Geometry | — | 输入网格 |
| **Selection** | Bool | true | 面选择 |
| **自定义偏移** | Vector | (1,1,1) | 自定义偏移方向 |
| **Offset Scale** | Float | 1 | 偏移厚度 |
| **描边权重** | Float (0-1) | 1 | 描边权重控制 |
| **翻转法向** | Bool | false | 翻转法线 |
| **Material** | Material | — | 背面材质 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 实体化结果 |
| **Top** | Bool | 顶面选择 |
| **Side** | Bool | 侧面选择 |
| **Back** | Bool | 背面选择 |

## 对称(镜像)

沿平面镜像几何体，支持焊接对称点。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Geometry** | Geometry | — | 输入几何体 |
| **对称中心** | Vector | (0,0,0) | 对称中心位置 |
| **镜像平面** | Int (1-3) | 1 | 1=YZ, 2=XZ, 3=XY |
| **焊接点** | Bool | false | 焊接对称点 |
| **Distance** | Float | 0.001 | 焊接距离阈值 |
| **Material** | Material | — | 镜像部分材质 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 对称后的几何体 |

## 晶格管道

沿网格边生成管道和球体，用于创建线框/晶格效果。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Mesh** | Geometry | — | 输入网格 |
| **Selection** | Bool | true | 边选择 |
| **管道半径** | Float | 0.02 | 管道粗细 |
| **球体半径** | Float | 0.05 | 节点球大小 |
| **Resolution** | Int | 8 | 管道分段 |
| **对齐法向** | Bool | true | 对齐法线 |
| **自定义线** | Bool | false | 使用自定义曲线替代管道 |
| **曲线** | Geometry | — | 自定义曲线 |
| **自定义点** | Bool | false | 使用自定义实例替代球体 |
| **实例** | Geometry | — | 自定义实例 |
| **管道材质** | Material | — | 管道材质 |
| **圆材质** | Material | — | 球体材质 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 晶格结果 |
| **UV Map** | Vector | UV 坐标 |

## 桥接面

在两个面或物体之间创建桥接网格。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Geometry** | Geometry | — | 源网格/面 |
| **Selection** | Bool | true | 源面选择 |
| **Geometry** | Geometry | — | 目标网格/面 |
| **物体** | Object | — | 目标物体 |
| **Selection** | Bool | true | 目标面选择 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 桥接后的网格 |

## 破碎_峰峰居士

峰峰居士制作的 3D 沃罗诺伊破碎网格节点。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Geometry** | Geometry | — | 输入网格 |
| **分布密度** | Float | 2 | 破碎点密度 |
| **随机种子** | Int | 0 | 随机种子 |
| **缩放** | Float (0-1) | 1 | 碎片缩放 |
| **推开** | Float (0-1) | 0 | 碎片推开距离 |
| **栅格排列** | Bool | false | 栅格排列模式 |
| **混乱程度** | Float | 0 | 破碎混乱度 |
| **演化** | Float | 0 | 演化偏移 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Geometry** | Geometry | 破碎后网格 |

## 运动挤压

沿路径多次挤出网格，生成运动轨迹几何体。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Geometry** | Geometry | — | 输入网格 |
| **Selection** | Bool | true | 面选择 |
| **Steps** | Int | 3 | 挤出步数 |
| **Offset Scale** | Float | 0.2 | 每步偏移量 |
| **Position** | Vector | (0,0,0) | 位置增量 |
| **Rotation** | Vector | (0,0,0) | 旋转增量 |
| **Scale** | Vector | (0.8,0.8,1) | 缩放增量 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Mesh** | Geometry | 挤压结果 |
| **Top** | Bool | 顶面选择 |
| **Side** | Bool | 侧面选择 |

## 连接点

连接几何体顶点生成曲线，基于距离阈值。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Geometry** | Geometry | — | 输入几何体 |
| **距离** | Float | 1 | 连接距离阈值 |
| **全部连接** | Bool | false | 全部连接模式 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **曲线** | Geometry | 连接生成的曲线 |
| **长度** | Float | 每条曲线的长度 |

## 重构网格_ETK

ETK 制作的网格重构节点，基于体素和自适应方法。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **Mesh** | Geometry | — | 输入网格 |
| **Accurate** | Bool | false | 精确模式 |
| **Bounds Buffer** | Float | 0.1 | 边界缓冲区 |
| **Sample Size** | Float | 0.3 | 采样大小 |
| **Voxel Size** | Float | 0.3 | 体素大小 |
| **Adaptivity** | Float (0-1) | 0 | 自适应度 |
| **Remove Disconnected** | Bool | false | 移除不相连部分 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Mesh** | Geometry | 重构后的网格 |
