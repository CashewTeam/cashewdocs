# UV
用于着色器UV操作的节点组。

## 极坐标

UV极坐标效果，将直角坐标 UV 转换为极坐标。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **UV** | Vector | (2,2,2) | 输入 UV 坐标 |
| **rotation** | Float | 0.0 | 极坐标旋转角度 |
| **Factor** | Float (0-1) | 0.0 | 极坐标效果混合系数 |
| **演化** | Float | 0.0 | 演化偏移，用于动画 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **UV** | Vector | 极坐标变换后的 UV |

## 马赛克

UV马赛克效果，将UV划分为像素块，产生像素化/马赛克效果。

### 输入

| 名称 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| **UV** | Vector | (0,0,0) | 输入 UV 坐标 |
| **像素** | Float | 10.0 | 每行/列像素数量，越大马赛克越精细 |
| **圆大小** | Float (0-1) | 0.2 | 圆形像素块大小 |
| **亮度** | Float | 1.0 | 输出亮度调整 |

### 输出

| 名称 | 类型 | 说明 |
|---|---|---|
| **Vector** | Vector | 马赛克处理后的 UV 坐标 |
| **圆** | Float | 圆形像素块遮罩 |
